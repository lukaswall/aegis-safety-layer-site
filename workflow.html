A concept prototype. Teach with examples, run with rules.

A rule with a record.

Follow an output from the source example to the check, the verdict and the review.

Extract once

The proposed workflow extracts shared facts once, then reuses them across checks.

Each fact needs a connection to its source. Uncertain extraction should stay visible rather than becoming an apparently certain verdict.

Run the approved pack

A versioned check pack applies the approved rules to those facts.

Keep the pack version with the result so a reviewer can reproduce what happened. Checks can be toggled without rewriting the whole workflow.

Review the evidence

Keep source evidence beside the verdict. A reviewer should be able to see what triggered a check.

A corrected result becomes a reviewed example, not an automatic production change.

Replay the next version

Test updated rules against held-out examples before approving them.

The concept is a loop: examples, proposed checks, review, execution, evidence and replay. The landing page is a prototype, not a live product demo.
