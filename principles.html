A concept prototype. Teach with examples, run with rules.

Measure. Then trust.

A consistent answer is not necessarily a correct answer. The checks have to earn their place.

Cost

Measure total spend per workflow, including fact extraction, code execution and any remaining model calls.

Compare against the current workflow. No percentage saving is claimed before a real benchmark.

Agreement

Measure agreement with human labels per check, including false positives and false negatives.

Report coverage too. A low-cost check that misses the cases that matter is not a better check.

Time

Track latency per check and across the whole workflow.

A fast rule is useful only if extraction, orchestration and review do not erase the gain.

Control

Keep evidence and versions. Make it possible to inspect, replay and disable a check.

Humans approve changes before they reach production. Lower cost and greater accuracy are goals, not measured results.
